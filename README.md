# 武哥新标签页

Chrome 原生「添加快捷方式」需要手动填写名称和网址，且无法直接把当前打开的页面一键固定。本扩展替换新标签页，支持：

- **顶部书签栏**（读取浏览器书签栏，仅新标签页显示；打开网站后随页面离开而消失）
- **长期固定卡片**（保存在本机 `chrome.storage.local`，卸载前一直保留）
- **一键添加当前页面**（点击工具栏扩展图标）
- **悬停编辑 / 弹窗删除**、**长按拖动排序**
- 页脚署名「武哥出品 + 日期」
- **导入 / 导出卡片**（扩展管理 → 详细信息 → 扩展程序选项）

## 安装（开发者模式）

1. 打开 Chrome，进入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本仓库目录（克隆后的 `chrome-tab` 文件夹）
5. 安装后新标签页会显示「武哥新标签页」
6. （建议）在扩展详情里打开「在工具栏中固定」，方便一键添加

## 使用

| 操作 | 方法 |
| --- | --- |
| 一键添加当前页 | 打开任意网页 → 点工具栏扩展图标 → 确认名称 → 添加 |
| 手动添加 | 新标签页点「+」卡片 |
| 编辑 / 删除 | 鼠标经过卡片 → 点右上角编辑图标 → 可改名称/网址，或点「删除」 |
| 排序 | 长按卡片后拖动 |
| 打开卡片 | 单击卡片 |
| 导出 / 导入 | `chrome://extensions` → 武哥新标签页 →「详细信息」→「扩展程序选项」；或点工具栏弹窗里的「导入 / 导出设置」 |

> 说明：扩展替换新标签页后，Chrome 不会再自动弹出系统书签栏。本扩展用书签 API 在页面顶部复刻书签栏，效果接近原生「仅新标签页显示」。若你已开启「始终显示书签栏」(⌘⇧B)，系统栏会与页面内书签栏同时出现，可关掉系统「始终显示」以避免重复。

## 说明

- 无法添加 `chrome://`、`chrome-extension://` 等系统页
- 卸载扩展会移除自定义新标签页；同步存储中的数据也会随扩展清除
- 换电脑：在旧电脑导出 JSON，新电脑加载同一扩展后导入即可
